# basic

Minimal example showing how to register the `llm` library and call LLM inference primitives from Go.

Demonstrates: activation functions (`sigmoid`, `relu`, `gelu`, `silu`), vector ops (`vec_add`, `vec_sub`, `vec_mul`), `rms_norm`, `rope`, `attention`, `linear`, `silu_gate`, `dequantize_q8`, and more.

## Run

```bash
go run main.go
```
